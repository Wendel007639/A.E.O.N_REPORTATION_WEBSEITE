# Proof-Seite

Diese Seite ist die wichtigste Seite der A.E.O.N Reportation-Webseite.

Sie muss zeigen:

- Run-ID
- Run-Dir
- INTELLIGENCE_STATUS
- SMOKE_STATUS
- FINAL_EXIT_STATUS
- PROCESS_EXIT_STATUS
- FAILED_GATES
- PASSED_FALSE_REASON
- run_count
- max_run_count
- Tasks
- Dimensions
- Learning Metrics
- Speed Metrics
- Report Bundle
- Artefakte

Wichtigster Satz:

Ein grüner Prozessruecksprung ist kein Proof-Erfolg. Bewertbar ist nur ein Lauf, bei dem fachliche Gates und Artefakte konsistent gruen sind.

Regel:

Keine echte Grün-Behauptung ohne angebundene ProofKit-Artefakte.
